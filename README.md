# 3D 工作台

图片转 3D、GLB 预览、GLB 上色三合一的工作台。

在线使用：https://3698688050-pixel.github.io/3d-workbench/

> 本仓库是合并版，取代了此前两个分开的单一工具：`syg`（GLB 在线预览）和 `painter`（GLB 上色）。两个旧仓库已归档，功能全部在「GLB 预览」「GLB 上色」两个标签页里。

## 三个功能

| 标签页 | 功能 | 说明 |
|--------|------|------|
| 建模工具 | 图片转 3D | 精选免费 3D 生成网站入口（three.ws、Meshy、Tripo、TRELLIS 等） |
| GLB 预览 | 模型查看 | 本地 .glb 拖入即预览，单指旋转双指缩放 |
| GLB 上色 | 材质编辑 | 点选模型部位改颜色、金属度、粗糙度，导出 GLB |

## 关于原「AI 生图」

早期版本内置过一个文生图标签页（Pollinations / 硅基流动）。该功能已移除：它和 3D 工作流没有真正的衔接，却要额外维护两套第三方引擎和密钥存储。需要生图时用独立的服务更合适。

模型文件全程在浏览器本地处理，不上传任何服务器。
